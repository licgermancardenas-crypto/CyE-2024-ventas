# C&E Dashboard · Facturación 2024

Dashboard interactivo de análisis comercial construido con HTML/JS puro.

## Páginas

| # | Página | Descripción |
|---|--------|-------------|
| 1 | Resumen Ejecutivo | KPIs globales, tendencia mensual, top artículos y vendedores |
| 2 | Productos | Treemap por grupo, ranking artículos, participación por marca |
| 3 | Vendedores | Ranking, evolución mensual, dispersión tickets vs valor |
| 4 | Geográfico | Análisis por zona, provincia y local |
| 5 | Mapa | Mapa interactivo GBA + CABA con coropletas por partido/comuna |

## Stack
- HTML5 + CSS3 + JavaScript puro
- Chart.js 4.4.1
- Leaflet.js 1.9.4 (mapa)
- GeoJSON partidos GBA + comunas CABA

## Deploy
Conectar este repo a [Vercel](https://vercel.com) para deploy automático.
